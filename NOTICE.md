# Name und Bildmarke / Name and logo

**Deutsch**

Der Quellcode von lighthours steht unter der MIT-Lizenz (siehe `LICENSE`).
Du darfst ihn verwenden, ändern, weitergeben und auch kommerziell einsetzen.

Nicht Teil dieser Lizenz sind:

- der Name **lighthours**
- die Bildmarke (die drei gestapelten Balken) sowie die Dateien
  `assets/img/mark.svg`, `logo.svg`, `favicon.svg` und die daraus abgeleiteten
  Icons

Wer das Projekt forkt oder eine eigene Instanz betreibt, darf das gern tun –
aber bitte unter eigenem Namen und mit eigener Marke. So bleibt für Nutzer
erkennbar, woher eine Fassung stammt und wer sie betreut.

Eine unveränderte Instanz zu betreiben und dabei zu erwähnen, dass sie auf
lighthours basiert, ist ausdrücklich willkommen. Erst eine geänderte Fassung
unter demselben Namen wäre irreführend.

---

**English**

The lighthours source code is licensed under the MIT License (see `LICENSE`).
You may use, modify, redistribute and commercialise it.

Not covered by that licence:

- the name **lighthours**
- the logo (the three stacked bars) and the files `assets/img/mark.svg`,
  `logo.svg`, `favicon.svg` and the icons derived from them

Forks and self-hosted instances are welcome – please use your own name and your
own mark. That keeps it clear to users where a given version comes from and who
maintains it.

Running an unmodified instance and noting that it is based on lighthours is
explicitly fine. Only a modified version under the same name would be
misleading.
